# Provenance

`M0LTE.OfdmFm` is the adaptive OFDM-FM link modem from [pdn-soundmodem](https://github.com/packet-net/pdn-soundmodem), moved here with its namespace changed and part of its surface made internal, at pdn-soundmodem commit `97acf6711405d518deaf987a6cb1dee8341e56dc`. It was written for that project and carries its licence, AGPL-3.0-or-later.

The code came from `src/Packet.SoundModem/Modems/OfdmFm/Link/` (the code and its `Tables/`) and its tests from `tests/Packet.SoundModem.Tests/Modems/OfdmFm/Link/` (with `Vectors/`). `RealFft.cs` came from `src/Packet.SoundModem/Modems/OfdmFm/`, as an internal file of this package: M0LTE.Dsp's FFT is single precision, forward only and unscaled, and this modem needs a double-precision transform with a 1/N-scaled inverse, so it was not swapped. The earlier OFDM-FM files beside the `Link` folder in pdn-soundmodem are a different modem and did not move.

## Own design

The waveform, the list of standard formats, and the payload's LDPC family and its tables (`link-ldpc-protograph.txt`, `link-ldpc-shifts.txt`) are this project's own design. The training symbols (`link-training.txt`) are a fixed table generated by the prototype.

## The header code

The header code's table, `Tables/header-ldpc-bg2-set4.txt`, holds values of 5G NR LDPC base graph 2. They are taken from the published standard: ETSI TS 138 212 V15.11.0 (2021-08), 3GPP TS 38.212 version 15.11.0 Release 15, clause 5.3.2, Table 5.3.2-3 (LDPC base graph 2 and its parity check matrices V(i,j)), column set index 4. It is a table of numbers from the standard, not code. This is not a general 5G NR encoder.

## The design records and the vectors

The protocol is in [docs/adaptation-protocol.md](docs/adaptation-protocol.md), copied from pdn-soundmodem's `docs/dev/ofdm-fm/adaptation-protocol.md`. A `#N` in it is an issue in pdn-soundmodem, written there as `packet-net/pdn-soundmodem#N`. The test vectors in `tests/M0LTE.OfdmFm.Tests/Vectors/` were generated by the prototype, and the code is pinned to them; where a source comment says "the prototype", that is what it means.
